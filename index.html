01 — About

The short version

Started out as a full-stack generalist and ended up becoming the go-to person for anything payments-related on the team. Eventually moved into managing five engineers while still writing code myself.

Most of my last decade has been spent at the ENTERTAINER, where I went from shipping features to owning the backend for checkout, payments, refunds, and memberships — a platform serving 3M+ active members across 7 markets: UAE, KSA, Singapore, Oman, Qatar, Kuwait, and Bahrain.

Stack is mostly Vue.js (and React when the project calls for it) and Node on the frontend/backend, AWS for infra, and PHP (Laravel/Symfony) for the older systems that are still very much alive. On the UI side I go from Figma straight to code using MCP, and lean on AI-assisted tools — Claude, Cursor, Codex, and Google Antigravity — to move faster without handing over the architecture decisions.

Outside the day job I build and ship my own projects, end to end — three of them are below.
